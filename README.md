Program ini untuk menghitung total biaya pemesanan kamar hotel berdasarkan jenis kamar dan lama menginap.

-Fitur Program
Memilih jenis kamar Standard atau Deluxe
Memasukkan tanggal check-in dan check-out
Menghitung lama menginap berdasarkan selisih tanggal
Menghitung total biaya berdasarkan tarif kamar
Menampilkan detail pemesanan hotel

-Tarif Kamar
* Standard: Rp200.000/malam
* Deluxe: Rp350.000/malam

-Konsep Python yang Digunakan
Program menggunakan beberapa konsep dasar Python, yaitu:
Function untuk menghitung biaya pemesanan
Parameter untuk menerima jenis kamar dan lama menginap
Percabangan `if` dan `elif` untuk menentukan tarif kamar
Operator perkalian untuk menghitung total biaya
 `return` untuk mengembalikan hasil perhitungan
 `datetime` untuk mengolah tanggal check-in dan check-out
Input dan output untuk menerima data dan menampilkan hasil pemesanan

-Alur Program
1. Pengguna memasukkan jenis kamar
2. Pengguna memasukkan tanggal check-in dan check-out
3. Program menghitung lama menginap dari selisih kedua tanggal
4. Function menentukan tarif berdasarkan jenis kamar
5. Program menghitung total biaya
6. Hasil pemesanan ditampilkan ke layar

-Contoh Perhitungan
Jika memilih kamar Standard selama 2 malam:
`Rp200.000 × 2 = Rp400.000`
Program kemudian menampilkan jenis kamar, tanggal check-in, tanggal check-out, lama menginap, dan total biaya pemesanan
